# دستور العمل الدائم لمشروع كافيه سيزار (ceZar Coffee)
# Project Rules & Guidelines (.agent/rules/project_rules.md)

يلتزم المساعد الذكي وجميع المطورين بالتعليمات والقواعد الصارمة التالية كدستور عمل ثابت ودائم لهذا المشروع في كل الجلسات والمحادثات:

## 1. التخزين الفوري والمزامنة (Persistence & Real-time Sync)
- أي بيانات جديدة تُضاف أو تُعدّل أو تُحذف (طلبات، أصناف، مدفوعات، حركات مخزن، ورديات، خصومات) يجب حفظها ومزامنتها فوراً وبشكل دائم في قاعدة البيانات و localStorage وتحديث كافة الأرصدة، شاشات المطبخ والبار، والتقارير المرتبطة بها ديناميكياً ولحظياً دون تأخير أو حاجة لإعادة التشغيل اليدوي.
- حماية قاعدة البيانات الحية على السيرفر (Production DB) وعزلها تماماً عن تتبع Git لمنع أي تصفير للبيانات عند التحديث.

## 2. اكتمال الكود البرمجي البرودكشن (Production-Ready & No Mocks)
- ممنوع منعاً باتاً كتابة أي دوال فارغة أو مؤجلة (مثل `TODO`, `FIXME`, أو `pass` غير مبرر).
- ممنوع استخدام بيانات وهمية أو ثابتة (Mock Data, Hardcoded Placeholders, Mock Dates).
- كتابة المنطق البرمجي والمالي كاملاً وربطه بقاعدة البيانات SQLite/SQLAlchemy وحسابات الورديات والضرائب والخدمة والمخازن بدقة 100%.
- استخدام التواريخ والأوقات الديناميكية الحقيقية المتوافقة مع توقيت مصر/القاهرة والـ UTC بشكل سليم.

## 3. تطابق الأسماء والترجمة (Schema Consistency & Localization)
- مطابقة أسماء الحقول، المعاملات، والمتغيرات بين الـ Backend (Flask / SQLAlchemy Models) والـ Frontend (JS State / DOM APIs) بدقة تامة وبلا أي اختلاف في التسميات.
- أي نصوص أو تنبيهات أو رسائل جديدة في الواجهة يجب أن تكون ثنائية ومطابقة لقاموس المصطلحات (اللغة العربية والإنجليزية).
- الحفاظ على نفس نسق التصميم (Cezar Palette: Primary Espresso `#2B1810`, Cezar Gold `#C5A880`, Cezar Orange `#D97706`).

## 4. الاختبار والتحقق بعد التنفيذ (Verification, Refresh & QA)
- بعد أي تعديل أو ميزة جديدة، يجب فحص واختبار الميزة والتأكد من خلو سجلات الـ Console والـ Network من أي استثناءات أو أخطاء (Zero Console Errors).
- تجربة الميزة وعمل Refresh للصفحة للتأكد من ثبات واسترجاع البيانات المحفوظة وعدم فقدانها.
- التحقق من تكامل أزرار التعديل والحذف والطباعة وسلامة الربط مع مسارات السيرفر.
